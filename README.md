🚌 Bus Reservation System

A simple Bus Reservation System developed using Python as part of my Python Development journey.

📌 About the Project

The Bus Reservation System is a beginner-friendly Python project designed to simulate a bus ticket booking system. It allows users to view available buses, enter passenger details, and book seats through a menu-driven interface.

This project helps demonstrate basic Python programming concepts through a practical application.

✨ Features

- 🚌 View available buses
- 🗺️ Display bus routes
- 🎫 Book bus tickets
- 👤 Enter passenger details
- 💺 Select a seat number
- 📋 Display booking information
- 🔄 Menu-driven interface

▶️ How to Run

1. Clone or download this repository.
2. Open the Python file.
3. Run the program using Python.
4. Choose an option from the menu.
5. Enter the required passenger and booking details.
